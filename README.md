# Supermarket Sales EDA

## Project Overview
Exploratory Data Analysis of supermarket sales data using Python.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

## EDA Performed
- Data cleaning
- Missing value analysis
- Duplicate detection
- Outlier investigation
- Categorical data standardisation
- Sales analysis by product line
- City-wise sales analysis
- Customer type analysis
- Payment method analysis
- Date-based sales analysis
- Data visualisation

## Key Insights
- Health and beauty generated the highest total sales.
- Sports and travel generated the lowest total sales.
- Fashion accessories had more transactions than health and beauty.
- Health and beauty had a higher average transaction value.
